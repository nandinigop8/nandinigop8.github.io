CAD PROJECT · 01

Micropipette

Laboratory Instrument Design

OVERVIEW

Designing a multi-component laboratory instrument.

Designed and modeled a multi-component micropipette assembly to develop more advanced skills in parametric CAD, assemblies, and functional mechanisms.

The design includes a sliding plunger, threaded connecting collar, adjustable volume knob, and tip-ejection mechanism.

SKILLS USED
Parametric Modeling Assemblies Joints Lofts Patterns Threads Split Body Draft Shell Rendering
DESIGN FEATURES

Sliding Plunger

Modeled a movable plunger assembly using a slider joint.

Tip Ejection

Created a sliding tip ejector mechanism for removing the disposable pipette tip.

Threaded Collar

Added a threaded connection between the main housing and shaft assembly.
